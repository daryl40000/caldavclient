## Comment contribuer

Nous accueillons volontiers les contributions ! Voici comment participer :

1. **Signaler des bugs** : Ouvrez une issue sur le dépôt Git
2. **Proposer des fonctionnalités** : Ouvrez une issue pour discuter de votre idée
3. **Soumettre du code** : 
   - Fork le projet
   - Créez une branche pour votre fonctionnalité
   - Commitez vos changements avec des messages clairs
   - Ouvrez une Pull Request

## Standards de code

- Code conforme aux standards Dolibarr
- Commentaires en français pour la documentation utilisateur
- Commentaires en français ou anglais pour le code technique
- Tests pour les nouvelles fonctionnalités
